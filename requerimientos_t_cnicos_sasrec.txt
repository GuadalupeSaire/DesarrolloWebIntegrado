1. INFORMACIÓN GENERAL Y OBJETIVO DEL SISTEMA
--------------------------------------------------------------------------------
1.1 Nombre del Sistema: SASREC.
1.2 Propósito: Sistema web multiempresa para automatizar el reclutamiento y
    selección de personal (ATS) y el cálculo interno de planillas y boletas de
    las empresas cliente de GESCONT. No presenta información a SUNAT ni envía
    información a ninguna entidad o persona externa.
1.3 Modelo Operativo: Multiempresa lógico (aislamiento de datos por empresa cliente).
1.4 Roles: Administrador, Jefe de Reclutamiento (Jefe_Reclutamiento), Analista de
    Selección (Analista), Asistente de Reclutamiento (Asistente) y Encargado de
    Planillas (Planillas).

--------------------------------------------------------------------------------
2. ARQUITECTURA Y PATRONES DE DISEÑO
--------------------------------------------------------------------------------
2.1 Patrón: MVC de Spring con arquitectura en capas:
    Controller -> Service (@Transactional) -> Repository (Spring Data JPA) -> PostgreSQL.
2.2 Patrones: Repository, Service Layer y DTO para reportes (TrabajadorEmpresaReporte,
    DetallePlanillaReporte). Autenticación con Spring Security (formulario y sesión)
    y contraseñas con BCrypt.

--------------------------------------------------------------------------------
3. STACK TECNOLÓGICO
--------------------------------------------------------------------------------
Backend: Java 21, Spring Boot (Web, Data JPA, Security, Validation), PostgreSQL.
Frontend: Thymeleaf y Bootstrap.
Librerías: Apache PDFBox (lectura de CVs), JasperReports (reporte de terna y boletas).
Pruebas: JUnit 5 y Mockito. Control de versiones: Git / GitHub.
Se retiran del alcance: Spring Batch, JWT, Apache Tika y despliegue con Docker/Nginx.
